# 📱 Campus Mobile App

An Android application designed to help students manage their academic and social life on campus.

## Features
- Course schedule management (create, update, track)
- Event tracking system
- Announcements and campus updates
- Cafeteria rating and feedback system

## Architecture
- Language: Java
- Platform: Android
- Database: SQLite, Firebase Realtime Database
- Networking: Retrofit (REST API)
- Architecture Pattern: MVC

## Key Components
- RecyclerView & custom adapters for dynamic UI
- Local database operations (CRUD)
- Real-time data synchronization with Firebase

## Purpose
This project aims to provide students with a centralized mobile platform to manage their academic schedule and stay updated with campus activities.

## Tech Stack
Java, Android Studio, SQLite, Firebase, Retrofit
